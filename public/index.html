03dossiers sécurité

Cinq projets où la sécurité est dans le code, pas dans la description.

DOSSIER 01RÉSEAUDURCISSEMENT

Calypso — lab réseau durci

Passerelle Linux à trois zones (WAN, LAN, DMZ) protégeant un serveur interne et un intranet web. TP Réseaux B2.

  • nftables en liste blanche : policy drop sur input et forward
  • Règles dérivées d'une matrice des flux, une ligne = une règle
  • Suivi d'état conntrack, paquets invalides rejetés, ping limité à 5/s
  • DNAT pour publier le web en DMZ, masquerade en sortie
  • SSH : clé uniquement, root interdit
nftables · OpenSSH · NAT · Linuxlab local
DOSSIER 02APPSECAUTH

Crypto Arena

Simulateur de trading crypto à argent virtuel, prix réels, classement entre joueurs. React, FastAPI, PostgreSQL.

  • bcrypt, comparaison à temps constant, aucun indice sur l'existence d'un e-mail
  • JWT HS256 expirant, vérifié sur chaque route privée
  • Connexion Google / GitHub : signature Ed25519 vérifiée via JWKS, émetteur, audience, expiration
  • Le prix n'est jamais accepté du client ; transactions avec verrous ligne
  • CORS restreint, requêtes paramétrées, secrets hors dépôt
FastAPI · PyJWT · bcrypt · React · Docker code ↗démo ↗
DOSSIER 03APPSECDONNÉES

Traque — manhunt géolocalisé

Jeu de poursuite entre amis avec positions en temps réel sur carte. Next.js 15, Supabase, MapLibre.

  • Row Level Security Postgres : le navigateur n'a que la clé anon
  • Vue filtrée par rôle : un chasseur ne lit pas ce qu'un chassé voit
  • Toutes les entrées validées côté serveur avec Zod
  • RLS testée en SQL avec 6 comptes simulés, dont un extérieur à la partie
  • 14 scénarios multi-comptes automatisés
Next.js · Supabase · RLS · Zod · Vitest démo ↗
DOSSIER 04DONNÉESMOINDRE PRIVILÈGE

Bibliothèque de mangas

Base PostgreSQL de prêt de mangas, 200 005 emprunts. Projet SQL avancé B2, en groupe.

  • Rôles métiers NOLOGIN, un compte par personne qui en hérite
  • UPDATE accordé sur une seule colonne, e-mails des lecteurs illisibles au comptoir
  • Vues par profil : le gérant lit des statistiques, rien d'autre
  • Trigger qui fait respecter la règle métier dans la base elle-même
  • Index sur clé étrangère : requête environ 40 fois plus rapide
PostgreSQL · PL/pgSQL · GRANT · Docker code ↗
DOSSIER 05APPSECAPI

api-jeux

API REST d'un catalogue de jeux. FastAPI, SQLAlchemy, Pydantic, PostgreSQL.

  • Module securite.py : hachage bcrypt appelé directement, passlib étant incompatible avec Python 3.13
  • Vérification à temps constant, même pour un compte inexistant
  • Jetons JWT signés, clé secrète en variable d'environnement
  • Import CSV qui rejette les lignes invalides
  • Conteneurisé (API + PostgreSQL), ruff et pytest
FastAPI · bcrypt · JWT · Docker · pytest code ↗
